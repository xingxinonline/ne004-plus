## 🚀 使用方法

### 编译命令
```bash
cd S300_BSP/Projects/RBL/GCC
make clean              # 清理构建
make all               # 编译RBL
make debug             # 编译调试版本
make size              # 查看内存使用
make s300_image        # 生成完整镜像
```

### 烧录使用
1. 将 `build/s300_rbl_complete.bin` 烧录到Flash地址0x0000
2. 设置系统从Flash启动
3. 上电后RBL将自动运行
4. 串口115200波特率查看启动日志
5. 3秒内按任意键进入下载模式

### 下载模式测试
```
发送命令：
INFO  - 查看芯片信息  
QUIT  - 退出下载模式
```
