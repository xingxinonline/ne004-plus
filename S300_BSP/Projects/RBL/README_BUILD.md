## 使用说明

### 编译步骤
```bash
cd S300_BSP/Projects/RBL/GCC
make clean      # 清理构建
make all        # 编译RBL
make size       # 查看大小
make s300_image # 生成完整镜像
```

### 调试版本
```bash
make debug      # 编译调试版本
```

### 内存布局
- **目标平台**: S300 PiMCHIP Cortex-M4
- **运行内存**: SRAM (0x20000000, 256KB)
- **Flash存储**: QSPI W25Q128 (16MB)
- **SBL位置**: Flash 0x10000 (128KB)
