### 4. 地址配置不一致问题

#### 🚨 发现的问题：

1. **SBL Flash地址不一致**：
   - 文档建议：`0x80010000` (QSPI XIP)
   - RBL配置：`0x20000` (相对地址，实际为 0x80020000)
   - SBL配置：`0x00100000` (1MB地址，不符合16MB Flash)

2. **下载地址错误**：
   - RBL下载配置：`0x10000000` (SRAM0地址，应该是Flash)

3. **SBL运行方式不一致**：
   - 文档：QSPI XIP模式运行
   - 当前：Flash到SRAM复制运行

### 5. 修正建议

#### 🔧 推荐的统一配置：

```c
// === RBL配置 ===
#define RBL_SRAM_START          0x20000000    // RBL在SRAM运行
#define RBL_SRAM_SIZE           0x10000       // 64KB

// === SBL配置 ===  
#define SBL_FLASH_START         0x80010000    // SBL在Flash起始
#define SBL_FLASH_SIZE          0x20000       // 128KB
#define SBL_XIP_ENABLE          1             // 启用XIP模式

// === 下载配置 ===
#define DOWNLOAD_FLASH_START    0x80010000    // 下载到SBL分区
#define DOWNLOAD_MAX_SIZE       0x20000       // 最大128KB

// === 应用配置 ===
#define APP_FLASH_START         0x80040000    // 应用起始地址
#define APP_FLASH_SIZE          0x600000      // 6MB单分区或双分区
```
