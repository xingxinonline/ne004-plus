✨ Git 提交模板（Angular 风格，含 Emoji）

请使用仓库的提交规范，主题行示例：

✨ feat(repo): 添加 QSPI 寄存器定义增强

1. 背景
- 变更动机：简述为什么要改
- 问题定位：描述原行为或缺陷

2. 方案与实现
- 要点：列出 3-6 个核心修改点
- 影响面：列出受影响的模块/文件

3. 兼容性与迁移
- 兼容性说明与迁移建议

4. 风险与回滚
- 风险：可能引发的问题
- 回滚：`revert: <commit sha/描述>`

5. 验证
- 构建：`make` 或相应命令
- 运行：关键运行验证步骤

6. 关联
- Issues：#

多 -m 片段模式示例：
- m1：✨ feat(repo): 添加 QSPI 寄存器定义增强
- m2：1. 背景\n- 变更动机：简述为什么要改\n- 问题定位：描述原行为或缺陷
- m3：2. 方案与实现\n- 要点：列出 3-6 个核心修改点\n- 影响面：列出受影响的模块/文件
